# Сервис учётных записей

Действуют [корневые инструкции](../AGENTS.md). Команды - из `auth-api`.

Пакет `src/dvizh_auth/`: `main.py` - HTTP-контракты, `service.py` - регистрация,
`models.py` и `database.py` - хранение, `config.py` - настройки.
Миграции принадлежат этому сервису и находятся в `alembic/`.

Сохраняй хеширование паролей через существующий Argon2-механизм.
Не храни и не логируй исходные пароли, не включай пароль или хеш в ответы API.
Сохраняй валидацию email/пароля и обработку повторной регистрации.
Не расширяй публичный доступ к сервису и не меняй границу с backend
без проверки маршрутизации и контрактов.

Установка: `uv sync --locked`.
Проверки: `uv run ruff check .`, `uv run pytest`.
Локальный запуск: `uv run uvicorn dvizh_auth.main:app --reload --port 8003`;
нужны настройки и доступная БД.
Миграции запускаются отдельно: `uv run alembic upgrade head` только для выбранной
локальной/тестовой БД. Не предполагай, что запуск uvicorn применяет их автоматически.
