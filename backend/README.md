# Пользовательский слой backend

`dvizh_backend.services.UserService` управляет доменным профилем и дружбой. Он принимает
UUID пользователя от доверенного вызывающего кода. Проверка паролей, токенов и выпуск UUID
относятся к `auth-api`.

Граница слоёв:

- `dto/user.py` валидирует входные данные и задаёт форму результата. Лишние поля и
  неясные частичные обновления отклоняются сразу.
- `services/user_service.py` проверяет активность профиля, уникальность имени,
  принадлежность готового аватара пользователю и переходы дружбы.
- `database/services/catalog.py` и `database/services/social.py` выполняют прямые запросы
  и запись через одну `AsyncSession`. Правил дружбы в них нет.
- `database/database_service.py` создаёт сессию для запроса, фиксирует успешную
  операцию и откатывает её при ошибке. Методы `UserService` не делают `commit`.

Для FastAPI доступна зависимость `services.dependencies.get_user_service`.
`create_profile` вызывается после успешного создания учётной записи в auth-сервисе.
Сейчас у `auth-api` нет регистрации и выдачи токенов, поэтому транспортный вызов
и API-маршруты профиля будут добавлены вместе с auth-контрактом.

Контракт сбора взаимодействий: [interactions.md](interactions.md).
