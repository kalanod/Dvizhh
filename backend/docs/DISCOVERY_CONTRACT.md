# Карта и лента мероприятий

`POST /api/events/discovery` — операция чтения. Карта и лента используют единый
набор кандидатов: `EventQueryService.public_statement`, затем `DiscoveryRepository`.
`EventDiscoveryService` координирует выбор области, кластеризацию и пагинацию;
`EventPresenter` формирует карточки также для существующих API. Роутер проверяет
HTTP-контекст и передаёт запрос сервису.

## Запрос

```json
{
  "filters": {
    "q": "", "tag_id": null, "date_from": null, "date_to": null,
    "free_only": false, "available_only": false,
    "viewer_id": null, "friends_of": null
  },
  "viewport": {
    "west": 29.9, "south": 59.8, "east": 30.6, "north": 60.1,
    "zoom": 11, "center": {"longitude": 30.3, "latitude": 59.95}
  },
  "sort": "distance", "selection_token": null,
  "cursor": null, "limit": 20, "include_map": true
}
```

Координаты — WGS84; `west > east` означает пересечение меридиана 180°.
Мировая область: `west=-180, east=180`. Нулевая площадь запрещена.
`viewport=null` возвращает ленту без географического ограничения и без карты.
Сортировки: `distance` (метры от центра), `newest`, `start`.
Без области `distance` эквивалентна `newest`. Режим друзей сначала поднимает
события с большим числом идущих друзей, затем применяет выбранную сортировку.

Личность определяется по проверенной cookie-сессии. Переданные `viewer_id` и
`friends_of` могут совпадать только с текущим аккаунтом, иначе 403. Они не дают
доступ к чужим персональным данным. Гость передаёт `null`.

## Ответ и правила отбора

Ответ: `{as_of, map: {items, total_events} | null, feed: {items, total_events,
next_cursor}}`. Полная схема и ограничения доступны в OpenAPI.

- Только опубликованные публичные неудалённые события с запланированным
  текущим или будущим проведением. Учитываются поиск, тематика, даты по поясу
  события, цена, наличие мест и персональное скрытие.
- Единица подсчёта — `event_id`. Среди подходящих проведений выбирается текущее,
  иначе ближайшее будущее. Это происходит до группировки и пагинации.
- При географическом ограничении нужны точные координаты места. События без
  координат и онлайн-события остаются доступны в ленте без области.
- Одна транзакция REPEATABLE READ READ ONLY согласует карту, счётчики и карточки
  одного ответа. Между страницами данные могут измениться; `as_of` фиксирует
  временную границу отбора, но не является длительным снимком БД.
- Карта содержит не более **30 объектов суммарно**. `event` имеет `count=1`
  и `event_id`; `cluster` — `count>1` и `selection_token`. У обоих есть `id`,
  координаты центра и `bounds` фактических точек, иногда нулевой площади.
- Сервер адаптивно делит мировую сетку Web Mercator; SQL агрегирует весь набор.
  LIMIT 31 используется лишь для обнаружения переполнения, после которого
  выбирается более крупная сетка. Отбрасывания событий ради лимита нет.
  Совпадающие точки остаются кластером при максимальном приближении.

Нажатие на кластер передаёт его непрозрачный `selection_token`. Лента фиксирует
пересечение исходной области карты с ячейкой кластера, включая исходный центр
сортировки. Последующее движение карты обновляет её независимо от выбранной
группы. Сброс выбора снова связывает ленту с текущей областью. Изменение фильтров
сбрасывает выбор. Одиночная точка открывает мероприятие.

`next_cursor` — подписанная keyset-позиция; передавайте её с теми же фильтрами,
выбором, областью и сортировкой. `include_map=false` позволяет получать следующие
карточки без повторной кластеризации. Порядок стабилизируется датой и UUID.
Подмена, истечение или несовместимый контекст токена возвращают 409; клиент
сбрасывает выбор/пагинацию и загружает свежую выдачу. Токены действуют 600 секунд.
Ответы имеют `Cache-Control: private, no-store`.

## Индекс и эксплуатация

Миграция `20261117_discovery_geo` подключает PostGIS, добавляет вычисляемую
`locations.position geometry(Point,4326)` и GiST-индекс. Координаты остаются
единственным источником данных; точка автоматически меняется при их обновлении.
Ограничение области использует индексируемый `ST_Covers`. Образ postgres
содержит PostGIS и сохраняет PostgreSQL 17; существующий volume сохраняется.
На внешней БД расширение должно быть установлено, а миграционной роли нужны
права CREATE EXTENSION либо расширение заранее создаёт администратор.

`DISCOVERY_TOKEN_SECRET` — отдельный секрет подписи длиной от 32 символов.
Задайте одинаковое стабильное значение всем экземплярам backend. При пустом
значении генерируется временный ключ процесса: после перезапуска старые токены
получат 409. Секрет авторизации для этого не используется.

## Клиент

`useEventDiscovery` владеет фильтрами, областью, выбором и страницами.
`EventDiscoveryMap` только управляет SDK, камерой и маркерами; `EventSection`
отображает общую выдачу. SDK не выполняет дополнительную кластеризацию.
Камера восстанавливается из sessionStorage, затем берутся координаты профиля,
иначе обзор Санкт-Петербурга. Кнопка «Найди меня» использует геолокацию
устройства; при отказе карта продолжает работать. При недоступности карты
лента работает без географического ограничения.
Кнопки «Свернуть» и «Развернуть» скрывают и показывают содержимое блока,
сохраняя экземпляр карты, камеру и выбранную группу. Пока карта свёрнута,
изменения размера скрытого контейнера не меняют область выдачи.

После завершения движения карты запрос откладывается на 300 мс. Кеш в памяти
хранит до 30 полных ответов на 60 секунд с LRU-вытеснением; ключ включает
фильтры, пользователя, камеру, сортировку, выбор и курсор. Запросы объединяются,
отменяются при отсутствии подписчиков, устаревшие ответы не заменяют текущие.
После персональных изменений кеш сбрасывается. События не пишутся в localStorage.
Маркерный слой заменяется согласованно, без объединения разных кластеризаций.

## Проверка

`tests/test_discovery.py` проверяет бюджет объектов, полноту группировки,
совпадающие координаты, границы мира, токены и HTTP-проверки личности.
`tests/test_discovery_integration.py` запускается при `TEST_DATABASE_URL`, только
на отдельной мигрированной PostGIS-базе: реальная кластеризация, keyset-страницы,
повторы, видимость, выбранная область и пересечение меридиана 180°.
