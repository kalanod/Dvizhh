# Тестовые пользователи

[Основной README](../README.md)

Набор `01b944fc`: 50 синтетических пользователей, созданных 14 ноября 2026 года
в локальной БД через API регистрации и создания профиля.
Тот же набор добавлен через API в серверное окружение `/srv/projects/dvizh`.
Это описание существующего набора, а не скрипт наполнения:
при развёртывании проекта в другой БД эти пользователи автоматически не появятся.

У каждого пользователя есть учётная запись `auth-api` и профиль backend
с одинаковым UUID. При создании для всех 50 проверены вход и получение профиля.
UUID на сервере отличаются от локальных; username, email и содержимое профилей совпадают.
При подготовке документа повторно прочитаны все 50 профилей; их статус — `ACTIVE`.
Имена в таблице сохранены в том виде, в котором записаны в БД.
Города и интересы переведены на русский; в полях `city` и `bio` они записаны
по-английски. Каждый `bio` также отмечает, что профиль тестовый.
Интересы — текст описания профиля, а не отдельно назначенные категории рекомендаций.

## Учётные записи

Username имеет вид `demo_01b944fc_NN`, где `NN` — номер от `01` до `50`.
Email каждого пользователя: `<username>@example.com`.
Например, для первого пользователя — `demo_01b944fc_01@example.com`.

Пароли сгенерированы случайно, проверены при входе и не сохранены в открытом виде.
Для ручного входа потребуется отдельно задать новый пароль выбранной тестовой учётной записи.

## Состав набора

В каждом из пяти городов — по 10 пользователей; каждому из десяти направлений
интересов соответствуют 5 профилей.
При первоначальной генерации создавались только учётные записи и профили.
Для этих пользователей подготовлен отдельный [набор из 300 мероприятий с участием
и заявками](test-events.md). Дружеские связи и приглашения генератор не создаёт.
